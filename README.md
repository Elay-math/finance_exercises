# Financial Algorithms

A collection of algorithmic problems focused on **finance, trading, and quantitative methods**, implemented primarily in Python.

The purpose of this repository is to develop and document algorithmic problem-solving skills while exploring concepts that appear in financial computing and quantitative finance.

Each problem includes a description, solution approach, implementation, and complexity analysis.
